# Spring Boot REST Application

This repository contains a simple Spring Boot–based REST application created as part of
my early learning process in Java and backend development, prior to starting my
university studies.

The main purpose of the project was to learn Java in a practical context and to
understand how a backend system is structured, how REST APIs work, and how a backend
connects to a database.

## Technologies used
- Java
- Spring Boot
- Spring Data JPA (Hibernate)
- PostgreSQL
- REST API
- MVC architecture (Controller / Service / Repository)

## What this project demonstrates
- Basic structure of a Spring Boot application
- Simple REST endpoints (e.g. GET requests)
- Database integration using JPA/Hibernate
- Object-relational mapping between Java objects and database tables
- Separation of concerns using MVC principles

## Scope and level
This is a **beginner-level project** created for learning purposes.
The focus was on understanding concepts and structure rather than building
a production-ready application.

## How the application was run during development
The backend was run locally using:
mvn spring-boot:run


This project is shared for learning and transparency purposes.
